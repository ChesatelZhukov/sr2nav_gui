## SR2NAV GUI — краткая инструкция по запуску `.exe`
---

### 1. Состав папки приложения

В папке, где лежит `SR2NAV_GUI.exe` при первом запуске должны быть:

- сама программа GUI: `SR2NAV_GUI.exe`;
- программа определения интервала: `Interval.exe`;

Рабочие файлы jps и другие автоматически копируются в директорию приложения при запуске обработки;

> **Важно:** запускайте `SR2NAV_GUI.exe` из папки, в которой есть права на запись (НЕ из защищённого `Program Files`), чтобы программа могла создавать файлы результатов.


### 2. Главное окно — быстрый обзор

Верхняя часть окна:

- кнопки запуска:
  - **▶ SR2Nav** — запуск только расчёта SR2Nav;
  - **⏱ Интервал** — определение интервала по данным (Interval.exe);
  - **▶▶ Полный цикл** — сначала интервал, потом SR2Nav;
  - **⏹ Стоп** — остановка текущего расчёта.
- статусная строка внизу — показывает, что происходит (готово, идёт расчёт, ошибки и т.п.).

Левая часть:

- блок **«Входные файлы»** — сюда вы указываете пути к `SR2Nav.exe`, JPS, POS, AIR и т.д.;
- блок **«Параметры обработки»**:
  - время **начала/конца** интервала;
  - **угол отсечения** в градусах;
  - кнопка **«Исключить спутники»** — выбор спутников, которые не должны участвовать в расчёте.

Правая часть:

- окно вывода сообщений — показывает ход работы и предупреждения;
- внизу — строка с индикатором выполнения и текущим статусом.

---

### 3. Подготовка к расчёту

1. **Укажите путь к SR2Nav.exe**  
   В блоке «Входные файлы»:
   - строка **«📦 SR2Nav (exe)»**;
   - нажмите кнопку `📁` и выберите `SR2Nav.exe` в текущей папке.

2. **Укажите файл ровера (JPS)**  
   - строка **«🚙 Ровер (JPS)»**;
   - выберите основной JPS‑файл ровера.

3. **Укажите файлы баз (при наличии)**  
   - строки **«🏠 База 1 (JPS)»**, **«🏠 База 2 (JPS)»** — выберите соответствующие файлы.

4. **Укажите файлы POS баз** (если нужны для вашего сценария):
   - **«📍 POS базы 1»**, **«📍 POS базы 2»**.

5. **Укажите файл гравики (AIR)** (если используется):
   - строка **«🌍 Гравика (air)»**.

6. **Угол отсечения**  
   - в блоке «Угол отсечения» выберите нужное значение (по умолчанию 7.0°);
   - при необходимости нажмите **«💾 Угол»**, чтобы сохранить его в конфиг (`Mask.Ang`).

---

### 4. Типичные сценарии запуска

#### 4.1. Полный цикл (рекомендуется)

Этот режим автоматически:

1. Очищает старые результаты (при необходимости).
2. Подготавливает файлы.
3. Запускает `Interval.exe` для определения интервала времени.
4. Применяет найденный интервал.
5. Запускает `SR2Nav.exe` для основного расчёта.
6. Переносит результаты в папку `results` (или отдельную папку с именем ровера).

**Как запустить:**

1. Убедитесь, что указаны **SR2Nav.exe**, ровер и (по возможности) базы и гравика.
2. Установите желаемый **угол отсечения**.
3. Нажмите кнопку **«▶▶ Полный цикл»**.
4. Ждите завершения:
   - внизу появится сообщение о конце работы;
   - в окне вывода будут строки вида «Результаты сохранены в: ...».

Результаты можно найти в подпапке `results` (или в папке с названием по роверу).

#### 4.2. Только определение интервала

Если нужно **посмотреть и/или подправить интервал времени**:

1. Укажите JPS‑файлы (как минимум файл ровера).
2. Нажмите **«⏱ Интервал»**:
   - программа подготовит конфиг;
   - запустит `Interval.exe`;
   - прочитает `interval.txt`;
   - автоматически заполнит поля «Начало» и «Конец».
3. При необходимости отредактируйте интервал вручную и нажмите маленькую кнопку **«💾»** справа от полей — интервал будет сохранён как ручной.

#### 4.3. Только запуск SR2Nav

Если интервал уже известен и конфиг готов:

1. Убедитесь, что в поле **SR2Nav (exe)** выбран правильный `SR2Nav.exe`.
2. Заполните остальные файлы (JPS, POS, AIR и т.п.).
3. Нажмите **«▶ SR2Nav»**.
4. Дождитесь завершения и сообщения о том, куда сохранены результаты.

---

### 5. Где искать результаты

После успешного расчёта:

- В консоли вывода появится строка:

  - `📁 Результаты (...) сохранены в: <имя_папки>`

- В рабочей директории будет:
  - папка `results\` или
  - папка с именем, совпадающим с именем файла ровера (без расширения), например `Rover_2024_09_22\`.

Именно там находятся файлы `*.VEL`, QC‑файлы и прочие результаты SR2Nav.

---

### 6. Анализ результатов (дополнительно)

Если вам нужно **не просто получить файлы**, а оценить качество:

- В верхнем меню выберите:
  - **Анализ → Анализ скоростей (VEL)** — построение графиков скоростей и сводки;
  - **Анализ → Анализ GPS созвездия** — оценка стабильности спутников.

Откроются отдельные окна, где можно:

- менять масштаб (колесо мыши, выделение прямоугольника);
- двигать график средней кнопкой мыши;
- копировать время и координаты точек.

Эти окна **не обязательны** для простого запуска, но помогают визуально проверить результат.

### 7. Частые вопросы

**1. Программа пишет, что не найден SR2Nav.exe**  
Проверьте, что:

- `SR2Nav.exe` реально лежит в той папке, где вы его выбираете;
- путь к нему выбран в строке **«SR2Nav (exe)»**.

**2. Interval.exe отрабатывает, но интервал не появляется**  
Проверьте, что:

- в папке приложения появляется файл `interval.txt`;
- в нём есть строка с `[Common]`.  
Если файл повреждён или пустой, интервал считать не получится.

**3. Ничего не происходит / окно «зависло»**  
Подождите некоторое время — обработки могут занимать минуты. Если совсем нет движения:

- нажмите **⏹ Стоп**;
- проверьте, что все необходимые файлы выбраны и находятся в доступной для записи папке;
- попробуйте снова запустить **полный цикл**.

**4. Как обновить только угол отсечения?**  

- Измените значение в поле **«Угол отсечения»**;
- нажмите кнопку **«💾 Угол»** — программа обновит внутренний файл `Mask.Ang`.

---

### 8. Что делать при ошибке

Если появилось красное сообщение об ошибке:

1. Прочитайте текст в нижнем окне — там обычно указано, какой файл не найден или что именно пошло не так.
2. Проверьте пути к файлам во входном блоке.
3. Если проблема повторяется, сделайте скриншот окна и передайте его разработчику/поддержке.
